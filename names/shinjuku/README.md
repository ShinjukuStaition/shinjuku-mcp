# shinjuku

The `shinjuku` command of Shinjuku Shield: a self-custody wallet that pays
x402 URLs privately from a shielded USDC balance on Solana. This package runs
the wallet package `shinjuku-shielded` at the exact version it names (the
same version number as this package). Your keys never leave your machine.

```sh
npm install -g shinjuku@0.3.80
shinjuku setup
```

Every wallet command works the same way after `shinjuku`, for example
`shinjuku balance` or `shinjuku help`.

Docs, host configs and the release table:
https://github.com/ShinjukuStaition/shinjuku-mcp
