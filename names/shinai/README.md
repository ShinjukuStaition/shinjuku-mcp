# shinai

`shinai` is a name of Shinjuku Shield (private AI inference, paid with x402): a self-custody wallet that pays x402 URLs privately from
a shielded USDC balance on Solana.

This package installs nothing. It prints how to install the wallet:

```sh
npm install -g shinjuku-shielded@0.3.80
shinjuku-shielded setup
```

Docs and host configs: https://github.com/ShinjukuStaition/shinjuku-mcp
